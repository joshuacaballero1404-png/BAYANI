Projects

My class project, made with a team of five.

BAYANI 3D: Heroic Arena

  • Typing game
  • Three.js / WebGL
  • HTML, CSS, JavaScript
  • Group project

A survivor finds a relic that lets them call on Filipino heroes by typing their names. Read the name above an enemy, type it, attack, and survive the waves. The game runs in the browser on desktop and on mobile.

Play the game

My contribution

  • Served as Project Manager for the five-person team.
  • Helped set the roles: programming, documentation, audio and UI/UX.
  • Followed up on deadlines so the game and the presentation were finished together.
  • Helped put the BAYANI game magazine presentation together, from story and characters to the interface and credits.

How the game works

  • Type the hero name shown above an enemy to attack.
  • Correct names in a row raise your combo.
  • Typing charges the Ultimate; press Space to use it.
  • Hearts show your lives. Waves get harder.
